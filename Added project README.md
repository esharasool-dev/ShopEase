# ShopEase – E-Commerce Website

ShopEase is a responsive e-commerce website designed to provide a simple and smooth online shopping experience. It features a clean interface, product browsing, and an easy-to-use layout for exploring products.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Clean and user-friendly interface
- Product listing using Fake Store API
- Dynamic product rendering
- Product details view
- Light and dark mode
- Interactive navigation menu
- Smooth user experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fake Store API
- Font Awesome

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/esharasool-dev/ShopEase.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

This project was developed to practice front-end web development skills, work with APIs, and build an interactive and responsive e-commerce website using HTML, CSS, and JavaScript.
